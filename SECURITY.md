# Güvenlik politikası

Güvenlik açıklarını herkese açık issue olarak paylaşmayın. Repository sahibine
özel bir kanal üzerinden aşağıdaki bilgileri iletin:

- Etkilenen sürüm veya commit
- Yeniden üretme adımları
- Olası etki
- Varsa önerilen düzeltme

API anahtarı, JWT, Fernet anahtarı, gerçek kullanıcı belgesi veya parola gibi
gizli verileri rapora eklemeyin. Doğrulanmış açıklar için düzeltme yayımlanana
kadar ayrıntıları gizli tutun.
