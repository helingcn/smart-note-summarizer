# Arayüz ekran görüntüleri

Bu klasör sürüm ve pull request ekran görüntüleri içindir.

Önerilen dosyalar:

- `main-desktop.png`: giriş yapılmış ana çalışma alanı
- `summary-desktop.png`: kaynak kanıtlarıyla tamamlanmış özet
- `main-mobile.png`: dar ekran görünümü

Görseller gerçek kullanıcı belgesi, e-posta adresi, API anahtarı veya başka kişisel
veri içermemelidir. PNG veya WebP kullanın ve gereksiz tarayıcı/masaüstü alanlarını
kırpın.
